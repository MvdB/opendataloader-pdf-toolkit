# Code of Conduct

This project adheres to the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants are expected to behave respectfully in all project spaces — issues, pull requests, discussions, and any related communication channels.

## Reporting

Report unacceptable behavior privately by opening a GitHub security advisory on this repository (the same channel used for security issues). Reports will be reviewed in confidence.
